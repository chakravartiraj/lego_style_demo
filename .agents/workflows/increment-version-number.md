# Increment Version Number

1. Read `project.yml` to find the `MARKETING_VERSION`.
2. Increment the patch version (e.g., `1.0.21` to `1.0.22`).
3. Save the file.
4. Run `xcodegen generate` to update the Xcode project.
5. Commit and push.
