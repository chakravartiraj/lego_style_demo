# 28. Apple Ecosystem Design & WCAG 2.2 Standards

- **Core Principle**: Strictly comply with Apple's Human Interface Guidelines (HIG).
- **Target Sizes**: Interactive elements **MUST** meet the minimum touch target size of 44x44 points.
- **Dynamic Type**: Fully support Dynamic Type scaling across the app.
- **VoiceOver**: Ensure all interactive flows can be completed entirely via VoiceOver without vision.
- **Color Contrast**: Enforce 4.5:1 minimum contrast ratios in both Light and Dark mode.
